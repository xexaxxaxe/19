# Практическая работа: Диагностика и исправление ошибок в Python-приложении

**Тема:** «Полевой архив — система учёта археологических находок».

**Цель:** освоить исследование поведения многофайлового приложения, проверку SQLite-данных, диагностику и исправление логических ошибок без нарушения остальных функций.

## Задание

1. Изучите назначение модулей, структуру таблиц SQLite и связи между компонентами.
2. Запустите приложение в Visual Studio Code и ознакомьтесь со всеми разделами.
3. Проверьте создание, изменение, удаление и поиск данных, сортировку, перемещения, лабораторные операции, историю изменений, статистику и экспорт.
4. Найдите **ровно 7 логических ошибок**. Для каждой зафиксируйте воспроизводимый пример некорректного поведения.
5. Определите первопричину ошибки по коду приложения, SQL-запросам и фактическим записям базы данных.
6. Исправьте исходный код, сохранив архитектуру, интерфейс и остальную функциональность.
7. Выполните повторную проверку проблемных сценариев и проверку сохранности данных после перезапуска.
8. Представьте полностью исправленный проект и отчёт.

## Что сдать

- Папку проекта со всеми исправленными Python-модулями и рабочей базой данных.
- Отчёт по каждой из 7 ошибок: наблюдение → шаги воспроизведения → причина → исправление → проверка.
- Скриншоты или другие свидетельства тестирования и проверки содержимого SQLite.
- Краткое заключение о том, какие операции были проверены после исправления.

## Правила

- Исправляйте логику, а не подменяйте данные ради совпадения результатов.
- Не удаляйте функции или элементы интерфейса для обхода неисправностей.
- Не нарушайте существующие ограничения, валидацию и сохранение данных.
- При выполнении опасных операций работайте с копией базы `data/archive.db`.

**Среда:** Python 3.11+, Tkinter, SQLite3, Visual Studio Code. Интернет для выполнения задания не требуется.
