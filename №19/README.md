# Полевой архив — система учёта археологических находок

Настольное офлайн-приложение на Python 3.11+, Tkinter и SQLite3. Интернет, внешние библиотеки, установка пакетов не требуются.

## Как запустить

1. Распакуйте ZIP полностью в отдельную папку.
2. Установите Python 3.11 или новее **с компонентом Tcl/Tk (Tkinter)**.
3. Откройте папку проекта в Visual Studio Code.
4. В терминале запустите:

   ```bash
   python main.py
   ```

   В Windows, если команда `python` не найдена, попробуйте `py main.py`.

5. Программа откроет окно с разделами «Находки», «Участки», «Хранилища», «Лаборатория», «Перемещения», «История изменений», «Статистика».

База уже включена в комплект: `data/archive.db`. В неё внесено 36 **вымышленных учебных** записей, демонстрационные перемещения и лабораторные заявки. Названия известных археологических мест используются как учебный контекст, данные не являются научным каталогом реальных находок.

## Что умеет приложение

- Создание, редактирование и удаление находок (включая проверку полей и идентификаторов).
- Учёт участков и хранилищ, передача находок между ними и журнал перемещений.
- Работа с датами обнаружения, глубиной, возрастом, категорией, материалом и сохранностью.
- Совместные фильтры по названию/номеру, категории, участку, хранилищу, интервалу глубины.
- Сортировка по основным параметрам; двойной щелчок открывает редактирование записи.
- Оформление лабораторных заявок, контроль периодов, завершение анализов и результат.
- Просмотр журнала изменений и статистики, CSV-экспорт **текущего результата поиска**.
- Постоянное сохранение информации в локальной SQLite базе после перезапуска.

Примечание: перемещайте находки кнопкой **«Переместить»**, а не через редактирование карточки — так сохраняется связанный журнал перемещений. Вместимость хранилища `0` означает отсутствие ограничений.

## Данные и резервная копия

Закройте приложение и скопируйте `data/archive.db` в другое место для резервного сохранения. Для запуска с другой базой:

```bash
python main.py --db data/another_archive.db
```

При создании пустой базы приложение автоматически заполнит её демонстрационными записями. Если в ней уже есть находки, данные не перезаписываются.

## Структура

`main.py` — запуск; `config.py` — настройки; `database.py` — схема, соединения и демонстрационные данные; `models.py` — модели; `validators.py` — валидация; `repository.py` — SQL-операции; `services.py` — бизнес-операции; `reports.py` — статистика и CSV; `ui.py` — Tkinter.

Никаких сетевых запросов приложение не выполняет.
